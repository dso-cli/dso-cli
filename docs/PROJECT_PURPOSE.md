# Project Purpose

DSO (DevSecOps Oracle) is a local-first DevSecOps assistant that helps developers identify and fix security issues quickly from the terminal.

## Why DSO Exists

Many security workflows are noisy, slow, and hard to prioritize. DSO focuses on:
- Actionable findings over alert noise
- Local AI analysis with Ollama
- Fast onboarding with minimal configuration

## Who It Is For

- Developers who want practical security guidance during development
- Platform and DevSecOps teams standardizing secure delivery
- Teams that prefer local processing and privacy by default

## Core Goals

- Reduce time from detection to remediation
- Prioritize exploitable and high-impact issues
- Improve security without adding operational complexity

## Project Vision

DSO aims to make secure software delivery simple, fast, and developer-friendly while remaining transparent and open source.
